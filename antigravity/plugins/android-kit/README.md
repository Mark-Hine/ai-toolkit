# android-kit

Android development plugin for Google Antigravity. Packages feature and bugfix playbooks, testing and dependency workflows, house standards references, rules generated from the canonical Claude rules, three specialist agents, and the shared PreToolUse guard.

## Skills

| Skill | Invocation | Purpose |
| --- | --- | --- |
| `android-feature` | `/android-feature` | Feature playbook: intake, pattern discovery, scoped plan, implementation, unit tests, device verification, review |
| `android-bugfix` | `/android-bugfix` | Bug-fix playbook: reproduction, root cause, minimal fix, regression testing, review |
| `android-run-app` | `/android-run-app` | Explicitly invoked build, install, launch and screenshot capture |
| `android-standards` | `/android-standards` | Reference index for official docs, Now in Android, JetSnack, UI events and testing |
| `android-uplift-deps` | `/android-uplift-deps` | Explicitly invoked toolchain and dependency upgrade with compatibility research |

## Rules (`rules/AGENTS.md`)

Generated by `../../scripts/sync_rules.py` from the Claude rules for Kotlin style, Compose, UI events and testing, plus the delegation section. Always on while the plugin is enabled. Never edit by hand.

## Specialist Subagents (`agents/`)

- `android-reviewer`: diff review (`model: pro`, read-only tools, commands need approval). Grades correctness, requirements, security and build health without writing code.
- `android-researcher`: platform and official documentation research (`model: flash`, read and web tools, commands need approval).
- `android-verifier`: test runner and emulator journey verification (`model: flash`, read tools, automatic command policy). Writes nothing.

## Hooks (`hooks.json`, `hooks/guard.py`)

The shared PreToolUse guard (`../../../shared/hooks/guard.py`, kept identical by CI) run as `python3 hooks/guard.py --agent antigravity`. It denies protected-branch, force and deletion pushes, destructive git, `timeout` wrappers and edits to secrets, signing material and lock files, and answers `ask` for everything else so the normal permission prompt applies.
