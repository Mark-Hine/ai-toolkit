# ios-kit

iOS and Swift development plugin for Google Antigravity. Packages feature and bugfix playbooks, simulator and dependency workflows, house standards references, rules generated from the canonical Claude rules, three specialist agents, the shared PreToolUse guard and the Swift lint hooks.

## Skills

| Skill | Invocation | Purpose |
| --- | --- | --- |
| `ios-feature` | `/ios-feature` | Feature playbook: intake, pattern discovery, plan, implement, tests, simulator check, review |
| `ios-bugfix` | `/ios-bugfix` | Bug-fix playbook: reproduce, root cause, minimal fix, regression test, review |
| `ios-run-app` | `/ios-run-app` | Explicitly invoked simulator build, install, launch and screenshot capture |
| `ios-standards` | `/ios-standards` | Reference index for Apple docs, SwiftUI data-flow, house patterns, and project instructions template |
| `ios-uplift-deps` | `/ios-uplift-deps` | Explicitly invoked Xcode/Swift/dependency uplift |

## Rules (`rules/AGENTS.md`)

Generated by `../../scripts/sync_rules.py` from the Claude rules for Swift style, SwiftUI, UI events and testing, plus the delegation section. Always on while the plugin is enabled. Never edit by hand.

## Specialist Subagents (`agents/`)

- `ios-reviewer`: diff review (`model: pro`, read-only tools, commands need approval). Grades correctness, requirements, security and build health without writing code.
- `ios-researcher`: Apple platform and official documentation research (`model: flash`, read and web tools, commands need approval).
- `ios-verifier`: runs tests and simulator checks (`model: flash`, read tools, automatic command policy). Writes nothing.

## Hooks (`hooks.json`, `hooks/`)

The shared PreToolUse guard (`hooks/guard.py --agent antigravity`) and the shared Swift lint (`hooks/swift_lint.py`). The lint runs SwiftFormat and SwiftLint on edited `.swift` files when the nearest config opts in. Its PostToolUse hook returns `{}` and records findings, and its PreInvocation hook hands them to the model as an ephemeral message on the next turn.
