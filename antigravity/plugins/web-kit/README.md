# web-kit

React, Next.js and TypeScript development plugin for Google Antigravity. Packages feature and bugfix playbooks, a dev server and screenshot workflow, house standards references, rules generated from the canonical Claude rules, three specialist agents and the shared PreToolUse guard.

## Skills

| Skill | Invocation | Purpose |
| --- | --- | --- |
| `web-feature` | `/web-feature` | Feature playbook: intake, pattern discovery, plan, implement, tests, browser check, review |
| `web-bugfix` | `/web-bugfix` | Bug-fix playbook: reproduce, root cause, minimal fix, regression test, review |
| `web-run-app` | `/web-run-app` | Start the dev server and capture routes with Playwright at phone and desktop widths |
| `web-standards` | `/web-standards` | Reference index for React, Next.js, TypeScript, testing and accessibility docs, companions, and project instructions template |

## Rules (`rules/AGENTS.md`)

Generated by `../../scripts/sync_rules.py` from the Claude rules for TypeScript, React and Next.js, and testing, plus the delegation section. Always on while the plugin is enabled. Never edit by hand.

## Specialist Subagents (`agents/`)

- `web-reviewer`: diff review (`model: pro`, read-only tools, commands need approval). Grades correctness, requirements, security and build health without writing code.
- `web-researcher`: framework guidance and package version research (`model: flash`, read and web tools, commands need approval).
- `web-verifier`: runs tests, type checks, lint and Playwright captures (`model: flash`, read tools, automatic command policy). Writes nothing but screenshots.

## Hooks (`hooks.json`, `hooks/`)

The shared PreToolUse guard (`hooks/guard.py --agent antigravity`), which limits the web agents to their documented commands.
